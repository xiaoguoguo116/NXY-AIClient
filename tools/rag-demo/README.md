# EM 本地知识问答演示

这是供桌面客户端试用的本机服务，不需要 Docker、模型账号或 API 密钥。

使用 Node.js 22 或更新版本，在本目录运行 `node server.mjs`，然后访问
`http://127.0.0.1:8090/`。在 EM 中进入“AI Work → 知识问答”，或在本地聊天中发送
`@AI RAG助手 请假应该怎么申请？`。

服务仅监听本机回环地址。四份虚构示例制度覆盖请假、报销、出差和远程办公，支持问题检索、
原文依据、同一对话内的追问和文档预览。回答采用本地关键词检索并摘录文档，不连接真实模型；
资料未覆盖的问题会明确说明没有依据，不会生成真实公司制度。

页面对话及服务端追问上下文仅保存在内存，刷新页面或重启服务会重置；通过 EM 聊天入口产生的
消息仍由 EM 原有的本地聊天机制保存。演示不会读取真实业务文档或访问外部接口。

兼容客户端当前使用的 `/config`、`/ragflow-api/chats/:chatId/sessions` 及
`/ragflow-api/chat/completions`，后者同时支持 JSON 和 SSE 返回。

在仓库根目录运行 `node --test tests/ragDemo.test.ts`，可验证接口及现有客户端 RAG 适配器。
