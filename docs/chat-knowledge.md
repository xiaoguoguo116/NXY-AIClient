# 群聊回溯基础版

在在线群聊或本地群聊顶部点击「问问本群」，输入 IP、接口名或事项关键词。侧栏仅自己可见，问题和回答不发送到群里。已有的「总设置 → AI 模型」配置用于生成回答；点击查询前会提示将问题及候选聊天片段发送到该模型服务。

## 当前能力

- 按需读取当前群本机已保存的文本，最多扫描最近 5000 条候选文本，不自动下载云端历史。
- 实体精确匹配、中文短语与少量同义词检索，同时保留早期和近期命中；补齐引用链及命中前后 30 分钟内的讨论，覆盖省略问题编号的后续更正。时间窗口内的消息只是候选上下文，不自动认定同一事项。
- 最多选择 80 条候选证据、约 48000 字符；单条长消息最多发送前 4000 字符，界面标明截取。
- 模型整理结论、进展、提议、决定、行动、阻碍、变更及确认。每条事实须带有效消息引用；无效引用或不完整结构不会显示为完成回答。
- 点击出处读取原始文本与相邻讨论，区分历史反馈、当前状态和未确认信息。
- 「问问本群」使用独立的明亮配色：白色侧栏、浅蓝信息块和深色正文，不受应用深色背景变量影响。
- 切换群或关闭侧栏会取消请求；当前消息变化时清空结果；生成结束、查看出处前重新读取快照核对变更。

## 实现入口

- `src/services/chatKnowledge.ts`：纯检索、证据预算、提示词和回答校验。
- `src/services/chatHistorySource.ts`：本地会话适配和上下文读取。
- `src/db/chatKnowledge.ts`：按当前账号、群隔离读取 SQLite 文本，不写原始记录。
- `src/components/Chat/ChatKnowledgePanel.vue`：独立查询与出处侧栏。
- `ChatSession.vue` / `LocalChat.vue`：在线／本地群入口，复用 `requestAi()`。

本版没有新增数据库表或持久化模型生成结果。账号切换后在线面板重建，证据查询始终带账号和群条件；本地演示数据使用现有本地会话来源，不混入在线群。网络模型凭证沿用现有配置。

## 已知边界

这是按需检索基础版，不包含持久化事项索引、后台分析队列、向量检索或自动任务执行。无关键词重合、没有引用且跨度较大的省略表达可能漏查。相邻消息只是候选上下文，不自动认为属于同一事项。引用编号校验只能确保出处存在，语义正确性仍需结合原消息核对。

覆盖区间只说明本机可检索文本的时间跨度，不能证明该区间完整。图片、语音、附件正文以及可识别的 AI 回复不参与检索。在线姓名优先使用当前成员名称缓存，缓存没有名称时展示成员 ID。后端若未同步撤回或修改，本机无法感知；其他窗口修改后在下次查询或查看出处时重新核验。

## 验证

```sh
node --test tests/chatKnowledge.test.ts
npm run type-check
node tests/check-chat-knowledge.cjs
```

界面测试自动在 1433 端口启动临时开发服务并在结束后关闭，使用隔离浏览器和模拟模型响应，不证明真实模型的回答质量或线上服务器历史完整性。Playwright 可通过 `PLAYWRIGHT_MODULE` 指定模块位置；也可通过 `TEST_ORIGIN` 使用已启动的开发服务。
