# 非银行支付机构监督管理条例

- 发布机关：国务院
- 施行日期：2024-05-01
- 主题：非银行支付机构准入、业务规则、用户权益、风险防控与监督管理。
- 权威来源：中国人民银行发布说明及条例信息
- 原文/说明链接：https://www.pbc.gov.cn/goutongjiaoliu/113456/113469/2025092212553651673/index.html

## 检索导读

条例将非银行支付机构及其支付业务活动纳入行政法规监管框架。监管重点包括依法许可、按许可范围经营、健全业务管理制度和业务系统、保障业务连续及安全可溯源、保护用户资金与信息安全、加强尽职调查和风险管理。支付机构须依法管理支付账户、支付指令与客户备付金；不得挪用、占用或借用客户备付金，不得伪造、变造支付指令，并应防范支付账户被用于违法犯罪活动。支付机构不得未经批准从事或变相从事清算业务。
