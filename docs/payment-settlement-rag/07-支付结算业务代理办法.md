# 支付结算业务代理办法

- 发布机关：中国人民银行
- 权威来源：中国人民银行支付结算司
- 原文链接：https://www.pbc.gov.cn/zhifujiesuansi/128525/128527/2829012/index.html

## 检索导读

办法规范银行之间办理人民币支付结算业务的代理关系。支付结算业务代理是银行一方委托另一方办理支付结算业务的行为，委托方为被代理行，受托方为代理行。制度内容涉及代理协议、凭证与专用设备管理、资金移存、准备金或同业账户资金保障、凭证审核及代理费用等职责。

## 使用提示

办理具体代理业务时应核对办法原文、支付结算凭证规则和双方协议约定。
