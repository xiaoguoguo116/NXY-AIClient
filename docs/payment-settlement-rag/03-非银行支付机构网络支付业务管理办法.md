# 非银行支付机构网络支付业务管理办法

- 发布机关：中国人民银行
- 发布形式：中国人民银行公告〔2015〕第43号
- 权威来源：中国人民银行正式文本
- 原文链接：https://www.pbc.gov.cn/zhifujiesuansi/128525/128527/541ae120fc6d4840836b4d089a82d94d/2015122817313737874.pdf

## 检索导读

办法适用于获准开展互联网支付、移动电话支付、固定电话支付、数字电视支付等网络支付业务的非银行机构。网络支付的识别要点包括：付款人或收款人通过计算机、移动终端等电子设备，依托公共网络远程发起支付指令；付款人设备不与收款人特定专属设备交互；支付机构为收付款人提供货币资金转移服务。

检索具体业务边界、实名与账户管理、交易验证、风险控制、信息留存和客户权益要求时，应结合办法原文及《非银行支付机构监督管理条例》等后续制度一并核对。
