# 非银行支付机构客户备付金存管办法

## 检索导读

办法规范客户备付金的存放、归集、使用和划转。客户备付金是非银行支付机构为办理客户委托支付业务而实际收到的预收待付货币资金；备付金集中存管账户是支付机构在中国人民银行开立、专门存放客户备付金的账户。制度核心是隔离和保护客户资金，按规定办理账户、划转、核对、信息报送及监督管理；客户备付金不得被挪用、占用或借用。
