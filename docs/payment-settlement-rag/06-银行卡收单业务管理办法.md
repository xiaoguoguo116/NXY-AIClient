# 银行卡收单业务管理办法

- 发布机关：中国人民银行
- 发布形式：中国人民银行公告〔2013〕第9号
- 权威来源：中国人民银行官方咨询答复引用该办法；人民银行官方文告收录相关收单要求
- 官方参考链接：https://wzdt.pbc.gov.cn/eportal/ui?msgDataId=84ac5f7a397d4142883380390a3bbe3a&pageId=77c3557bd521439ea5cd869f5393ba98
- 补充官方材料：https://www.pbc.gov.cn/chubanwu/114566/114579/2164312/2812943/index.html

## 检索导读

收单机构承担银行卡收单业务主体责任，应按规定开展商户资质审核、签约、交易处理和资金结算，遵循商户实名与“了解你的客户”要求，并真实、准确、完整传递交易信息。应管理受理终端及网络支付接口用途和风险，落实商户巡检与风险监测，并控制外包风险；收单外包不转移收单机构的管理责任。相关配套要求还涉及实体商户本地化管理、禁止特定投融资商户开通信用卡受理等场景。
