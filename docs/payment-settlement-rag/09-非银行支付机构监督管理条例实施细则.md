# 非银行支付机构监督管理条例实施细则

- 发布机关：中国人民银行
- 文号：中国人民银行令〔2024〕第4号
- 发布日期：2024-07-09
- 正式文本（人民银行）：https://www.pbc.gov.cn/zhengwugongkai/attachDir/2025/11/2025111915174857578.pdf
- 配套答记者问：https://www.pbc.gov.cn/rmyh/3963412/3963426/323775a2-2.html

## 检索导读

细则落实《非银行支付机构监督管理条例》，细化支付机构展业原则、行政许可及设立变更终止等监管事项。支付机构应遵循诚实信用、合法合规、安全高效原则，保障业务连续性、备付金安全和用户合法权益；不得以欺骗、隐瞒、非自有资金出资等不正当手段办理行政许可，也不得倒卖、出租、出借支付业务许可证。细则同时明确人民银行分支机构的监管分工。
