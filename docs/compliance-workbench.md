# 任务助手中的制度比对

AI Work 仅显示任务助手；制度比对从侧栏或首页快捷卡片进入。知识问答、合规助手和报送页面不再是 AI Work 入口，旧链接回到任务助手。应用中心仍可独立打开 RAGFlow。

1. 上传 TXT、Markdown、DOCX、文本型 PDF 或粘贴正文，保存到本机资料库。
2. 在两个下拉框中明确选择基准 / 旧版和新版 / 待比对文件。立即显示左右全文、行号、红色删除、绿色新增与字符高亮，可交换左右或只看差异。文字差异由本机计算，不调用模型。
3. 需要条款解释时填写任务说明，确认发送权限后调用全局模型。结果包含原文引证、修订草稿及需核实事项，不作最终合规认定。
4. 人工编辑审核状态和草稿并保存，可导出 Word。历史结果的 diff 使用当时的原文快照，当前选材与历史快照有明确的来源选择。

资料与历史保存在 `em-compliance-v1`，本次不删除既有数据。新旧文本比较是提取文本差异，不包含 Word 版式、修订痕迹或批注；移位段落可能显示为增删。大块不匹配文本使用完整块比较，避免二次方内存消耗，不截断原文。

文件限 15 MB / 30 万字符；PDF 限 150 页。AI 全文分析限 75,000 字符，超限明确拒绝。引用校验仅证明原文字面匹配，不能替代适用性审核。扫描页需先 OCR。

验证：`tests/documentDiff.test.ts` 覆盖中文高亮、增删、空文件、重复段落、大文档及随机输入重建；`tests/check-document-diff.cjs` 使用隔离浏览器和模拟模型验证交互、历史快照、审核保存。共享导入/导出逻辑由 `tests/check-compliance.cjs` 回归，后者仍保留对历史功能内部实现的兼容性测试。
