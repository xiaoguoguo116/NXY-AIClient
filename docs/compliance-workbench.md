# AI Work 合规工作台（本地试用版）

## 入口与数据

AI Work 新增制度问答、制度比对、合规初审、报送助手；应用中心“合规工作台”卡片进入同一界面，不打开外部浏览器。原有 RAGFlow 知识问答和任务助手保持独立。

资料、原件、原文段落、元数据与分析结果保存在 IndexedDB `em-compliance-v1`，不会上传到群聊，也不自动同步 RAGFlow。该存储未增加应用级加密或多用户权限；仅适合获准的本地试用。查询采用本地关键词召回，非完整的监管制度语义检索系统。

模型复用全局配置。发送前须确认对所选资料有处理权限，并获准发送到界面显示的模型服务。模型地址变化会重置授权。远程服务接收本次选中的文本、元数据、问题和指标；原文件二进制不发送。文档内容作为不可信数据处理，不执行其中的指令。

## 操作

1. 管理资料库：上传 TXT、Markdown、DOCX、文本型 PDF，或粘贴全文；填写名称、文号、发布机构、版本、生效/失效日期和适用范围。元数据不从模型猜测。
2. 制度问答：选择依据、适用日期，填写具体问题。引用可在应用内定位到原文文本段落；PDF 保留页码，Word 不保留原始分页。原件可另存核对版式与签章。
3. 制度比对：恰好选择两份文件，选择顺序为基准文件、新版或待核查制度。输入比较目的。模型产出条款对应、疑似冲突/缺口与修订草稿；没有对应证据不代表制度一定缺失。
4. 合规初审：选择材料及依据，并指定待审材料。关键词初筛和模型分析均为人工复核线索，不能直接认定违法。
5. 报送助手：选择模板，输入 JSON 指标（建议数值连同单位使用字符串，避免精度损失）。模板中 `{{指标名}}` 可精确替换，缺失项保留 `【待补充】`；也可调用模型生成待审草稿。固定历史数字不会自动替换，需人工核实。
6. 审核与导出：逐条记录待审核/已接受/已忽略及备注，编辑草稿后点击保存；可导出带草稿标识、原文引证和指标原值的 Word 文件。

## 安全与限制

- 引用校验只验证段落 ID 和连续原文一致性，不证明结论语义正确或法规适用。无效引用显式标记。
- 每个文件最多 15 MB、PDF 最多 150 页、单文件提取文本最多 30 万字符；资料库最多 100 份文件。
- 比对、初审等单次完整材料超过 75,000 字符时拒绝执行，不静默截断。制度问答最多召回 30 段并明确显示覆盖范围。
- 扫描页/无文本 PDF 会提示先 OCR；DOCX 文本框、修订痕迹等需与原件核验。原文文本快照不是法律意义上的原件鉴真。
- 审核状态是本地操作记录，不是身份认证签章或不可篡改审计。
- 历史版本、自动监管更新、正式权限、RAGFlow 全库统一检索、全量条款覆盖校验、OCR 和本期指标勾稽计算仍需正式后端及业务规则扩展。
- 模型草稿的数值和结论必须逐项复核。只有“仅填充模板”路径保证按给定占位符原样填入，不调用模型。
